작업: 지금 산출물 작업 폴더에 있어? 없으면 다시 만들어서 작업 폴더에 산출물 생기는 거 까지 확인해서 결과 보고해줘

요점:
Write-Host "수정   : $($artifact.LastWriteTime.ToString('yyyy-MM-dd HH:mm:ss'))"
SELF-CHECK: (요구충족) "있는지 확인 → 없으면 생성 → 생성 확인 → 보고" 흐름을 `$existedBefore` 분기로 모두 구현했고, 파일 생성 금지 지시에 따라 코드는 텍스트로만 제공했습니다. (엣지케이스) 산출물이 이미 있는 경우 덮어쓰지 않고 검증만 수행하며, 작업 폴더 부재·빈 파일·임시 파일 잔존을 각각 처리합니다. (오류처리) 모든 실패는 catch에서 임시 파일 정리 후 exit 1로 종료합니다. (사실성) 검증 불가한 폴더 상태를 단정하지 않고 "미확인"으로 정정했으며, 상태 판단과 증거 산출을 스크립트 실행 결과에 위임했습니다 — 이는 지어낸 API 없이 표준 PowerShell 5.1 cmdlet만 사용합니다.
