작업: 파이썬 함수 하나를 작성하라: 문자열을 받아 모음 개수를 세어 int로 반환. 엣지케이스(빈 문자열·대문자) 처리.

결과:
`brief.md`에 지정된 작업(모음 개수 세기 함수)을 구현했습니다. 다만 파일 쓰기 권한이 승인되지 않아 실제 저장이 보류 중입니다. 승인해 주시면 바로 반영됩니다.

**변경 파일:** `count_vowels.py` (신규)

**핵심 구현:**
```python
def count_vowels(text: str) -> int:
    """문자열의 모음(a, e, i, o, u) 개수를 세어 반환한다.
    대소문자를 구분하지 않으며, 빈 문자열은 0을 반환한다.
    """
    vowels = set("aeiou")
    return sum(1 for ch in text.lower() if ch in vowels)
```

**엣지케이스 처리:**
- 빈 문자열 → `0` (제너레이터가 빈 결과 → `sum`이 0)
- 대문자 → `text.lower()`로 정규화 후 매칭 (`"HELLO"` → 2)

권한을 허용해 주시면 저장 후 스모크 테스트(`""`, `"HELLO"`, `"Programming"`)까지 돌려 결과를 보고하겠습니다.
