작업: TeamFlow MCP 연동 스모크 테스트. 아래 순서로 도구를 호출하고, 각 호출의 원문 응답(issue id 포함)을 그대로 보고에 남겨라.
1) create_issue 도구로 프로젝트 key=YOK에 title='yok3x 연동 테스트', description='최초 생성 — yok3x MCP 스모크 테스트'로 이슈를 하나 생성한다.
2) 방금 만든 이슈 id로 get_issue를 호출해 내용을 확인한다.
3) update_issue_fields 도구로 같은 이슈의 description을 '갱신 완료 — yok3x MCP 스모크 테스트 (update_issue_fields 확인용)'으로 바꾼다.
4) 다시 get_issue로 description이 실제로 바뀌었는지 확인한다.
코드는 건드리지 말고 도구 호출과 결과 보고만 한다.
