# v4.x · 평가 — 오케스트레이터 자동 트리아지(착수 전 작업 규모 판단 → 티어 결정) · 2026-07-18

사용자 질문: "오케스트레이터가 작업 규모를 스스로 판단해서 에이전트 몇 개·루프 몇 번·바로 들어갈지
정하고, 가벼운 로컬모델을 트리아지용으로 둬서 크면 API로 넘기고 작으면 로컬로/직접 처리하게 해야 하지
않나?" → codex 공동검토. **결론: 방향은 채택, 단 "무료 규칙 → 추천 전용 → 저위험만 opt-in 자동화" 순서로.**

## 이미 있는 것 (중복 방지)
- `resolve_model(task_kind)`: 상황별 프로파일 픽(S1) + 벤치 폴백(S2). `escalate`: 점수 낮으면 런 중 워커 승격.
  `degrade_plan`: 한도 근처 다운그레이드. 로컬 백엔드(openai_http). 승인 게이트·요금 가드.
- **없는 것**: ① 착수 **전** 복잡도 추정 ② "에이전트 없이 직접/1샷" vs "로컬" vs "API+검토" 선택
  ③ 라운드 수 자동 결정 ④ "검토 생략" 결정.

## 핵심 통찰 (codex) — **규모 ≠ 위험**
단일 "규모" 등급으로 티어를 정하면 안 된다. 최소 4축을 분리:
- **복잡도**(얼마나 어려운가) · **실패 영향도**(틀리면 얼마나 위험한가) · **검증 가능성**(verify_cmd로
  객관 확인 되는가) · **비용**(예상 토큰/시간).
- 예: "배포 설정 한 줄 변경"=복잡도 낮음·**영향도 높음** → 검토 생략 금지. "50파일 포맷팅"=규모 큼·
  **검증 쉬움** → 로컬/직접 가능. 규모만 보면 정반대로 판단한다.

## 설계 결정 (codex + Claude 종합)
1. **트리아지는 얇은 앞단**(실행 '형태' 선택), `resolve_model` 대체 아님. **보수적 사전 추천 + 런 중 승격**:
   착수 전엔 싼/단순 쪽으로 낙관 시작하고, `escalate`(실제 실패 신호)가 "더 어렵네" 판정 시 올린다.
   → escalate가 추정보다 **정확·안전**(실제 신호 기반). 트리아지는 그 앞의 저비용 시작점만 고른다.
2. **무료 규칙부터. 로컬모델 트리아지 아님(초기).** 특징: 프롬프트 길이·파일 수·변경 범위·**외부 쓰기
   여부**·verify_cmd 존재·요청 모호성. 로컬모델은 실패모드가 많다(짧지만 어려운 것 과소, 장황하지만 쉬운
   것 과대, 콜드스타트, **입력에 의한 분류기 교란**=프롬프트 인젝션). 데이터 쌓인 뒤 규칙의 애매한 구간만 로컬 하이브리드.
3. **유료 자동 승급 = 기본 금지.** 예외는 사용자 사전설정 **작업별·일별 예산 내 opt-in**뿐:
   - 예산 내: 자동 승급 가능 + 실행 후 비용 보고 · 예산 초과 예상/비용 예측 불가/외부 쓰기: **항상 승인**.
   - **"알아서 다 해줘" = 품질·절차 위임이지 무제한 과금 동의가 아님**(yok3x 서프라이즈 비용 금지 원칙).
4. **자동화 우선순위**: `패턴 추천 > 라운드 수(상한 1~2) > 워커 티어 > 검토 생략`.
   **검토 생략이 가장 위험** — 작고 되돌릴 수 있고 **결정적 검증(verify_cmd)을 통과하는** 작업만 후보.
5. **선택 편향 주의**: 우리는 **고른 경로의 결과만** 관측한다(안 고른 경로가 더 나았을지 모름). 트리아지
   결정을 곧바로 정답으로 학습하면 편향. → 초기엔 **shadow 추천 + 사용자 override 데이터**를 먼저 모은다.
6. **F0 캘리브레이션 연결**: 트리아지도 SCORE처럼 **검증 안 된 판단기**다. 입력특징·추천/실제결정·신뢰도·
   override·verify결과·비용·지연·재수정을 기록해 F0에서 함께 보정. (CLIP 교훈의 재적용.)

## 단계별 (신규 로드맵 항목 T)
- **T1** `estimate_execution(spec) -> 추천`(순수 규칙, 4축): `{pattern, tier(direct|local|api), max_rounds,
  skip_review, 신뢰도, 근거}`. **추천 로그만**(자동 적용 X). 의존성0·무료. 호출 0.
- **T2** 저위험·무과금 경로만 opt-in 자동: `direct ↔ local 1-shot`. 유료 승급·검토 생략은 제외(수동/승인).
- **T3** 예산 게이트: 사용자 사전설정 예산 내에서만 유료 자동 승급(초과/외부쓰기=승인). C-2 예약 재사용.
- **T4** F0 데이터로 규칙 임계 보정 + (데이터 충분 시) 애매 구간만 로컬모델 하이브리드.
- **하지 않음**: 지금 단일 로컬모델 전권 트리아지(과설계·불안정). 네 결정 동시 자동화(오판 연쇄 증폭).

## 한 줄 결론
**무료 규칙 트리아지를 "추천·관측 전용"으로 먼저 넣고(T1), F0로 보정한 뒤 저위험 경로만 opt-in
자동화한다. 실패신호 기반 escalate는 유지, 유료 승급·검토 생략엔 독립된 강한 안전선을 둔다.**
규모가 아니라 복잡도·영향도·검증가능성·비용을 분리해 판단한다.
