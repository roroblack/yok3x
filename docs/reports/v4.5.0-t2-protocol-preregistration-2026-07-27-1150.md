# v4.5.0 · T-2 데이터 수집 프로토콜 **사전등록** · 2026-07-27 11:50

**목적**: T-1(심판 캘리브레이션 검증)에 쓸 (SCORE, verify_ok) 실데이터를 모으기 전에, 해석 규칙을
**데이터를 보기 전에** 고정한다. F2-4 항목 — 안 하면 "데이터는 모았는데 해석 불가"가 된다.

**이 문서는 데이터 수집 착수 전에 작성됐다.** 결과를 본 뒤 이 문서의 기준을 바꾸지 않는다.
바꿔야 할 이유가 생기면 **별도 문서로 사후 수정 사실을 남긴다**(CLIP 교훈: 사후 최적화 금지).

## 3. 측정 지표 (사전 확정)

**유효 관측**: `calibration.jsonl`에서 `verify_scope == "candidate"`인 행만 사용한다.
`original_tree`는 후보가 적용되지 않은 검증이라 **지상진실이 아니다**(BUG-40에서 확인).

- **주 지표**: 라운드별 `SCORE`(blind) ↔ `verify_ok` 관계 — 상관 + 2×2 혼동행렬(임계 8.0).
- **보조 1**: 임계 8.0에서의 게이트 통과율(정상 코드가 반려되는 비율 = N0′의 핵심 우려 재현 여부).
- **보조 2**: `stop_reason` 분포(`success`/`no_new_evidence`/`max_rounds`) — R-2 정지규칙 실제 작동 관찰.
- **비용**: `run_id`별 토큰·USD(원장) + 주간 % 변화.

## 4. 성공/회귀 판정 (사전 확정)

- **T-1 착수 가능**: 유효 관측이 독립런 ≥10 · `verify_ok=True` ≥3 · `verify_ok=False` ≥3.
- **N0′ 우려 재현으로 본다**: 정상 코드(verify_ok=True)인데 SCORE < 8.0인 관측이 **3건 이상**.
- **심판이 쓸모 있다고 본다**: verify_ok=True의 SCORE 중앙값이 verify_ok=False보다 **1.0점 이상** 높다.
- **임계 재설정은 이번 데이터로 확정하지 않는다.** 후보값이 보이면 **가설로만 기록**하고, 검증은
  별도 사전등록 + 새 표본으로 한다(N0′의 사후 최적값 t=4를 그대로 채택 금지한 것과 동일 이유).

## 5. 중단 조건 (사전 확정 — 하나라도 걸리면 즉시 중단)

1. **쿼터**: 수집 중 `yok3x pace --exit-code`가 **4(stop)** 또는 claude/codex 중 하나가 일 상한 초과.
2. **하네스 결함**: `verify_scope == "original_tree"`가 전체의 **30% 초과** → 데이터가 아니라 버그다.
3. **비용 이탈**: 실측 누적 비용이 **$10 초과**(파일럿 기준 12런 예상 $2~4의 2.5배).
4. **반복 실패**: 연속 3런이 `producer_failed`(백엔드 오류) → 환경 문제.
5. 사용자 중단 지시.

## 6. 범위 밖(이번에 하지 않는 것)

- **작업E A/B(blind vs 라벨누출 리뷰어)**: 누출 경로는 작업E에서 제거됐다. 비교하려면 실험용 플래그를
  다시 넣어야 하므로 **별도 사전등록·별도 수집**으로 분리한다. 이번 표본으로는 판단하지 않는다.
- **임계 재설정 확정**(§4 참조), **모델·effort 비교**(고정 조건이라 이번 표본으로 불가).
