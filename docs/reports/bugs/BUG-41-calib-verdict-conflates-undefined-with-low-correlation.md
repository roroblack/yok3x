# BUG-41 · 캘리브레이션 판정이 '계산 불가'를 '상관 낮음'으로 뭉갬

- **상태**: 수정 완료 (2026-07-27)
- **심각도**: 중간(데이터가 없는데 "게이트가 무의미하다"는 결론을 표시 — 잘못된 의사결정 유도)
- **영역**: `yok3x/calibration.py` `summarize`

## 증상

T-2 1차 수집(유효 관측 14건, 전부 `verify_ok=True`)에서 `yok3x calib` 요약이
`"verdict": "게이트 무의미 의심(상관 낮음)"`을 냈다. 그런데 같은 응답의 `score_verify_corr`는 **null**이었다.

## 근본 원인

```python
"게이트 무의미 의심(상관 낮음)" if (corr is None or abs(corr) < 0.2) else ...
```
`corr is None`(**계산 불가** — 라벨이 한쪽뿐이라 분산 0)과 `abs(corr) < 0.2`(**계산했더니 낮음**)를
같은 분기로 묶었다. 둘은 완전히 다른 상태다:
- 상관 낮음 = "측정했고, 게이트가 신호를 못 준다" → 게이트를 의심할 근거가 **있다**.
- 계산 불가 = "측정 자체가 안 됐다" → 게이트에 대해 말할 수 있는 게 **없다**.

전자로 표시하면 **없는 근거로 결론을 주장**하게 된다. 하필 T-1의 핵심 질문("게이트가 연극인가")이라
오판 비용이 크다.

## 수정

세 상태를 분리한다: `표본 부족`(n<10) · **`판정 불가(라벨이 한쪽뿐 — 상관 정의 안 됨)`** ·
`게이트 무의미 의심(상관 낮음)` · `게이트 신호 있음`.

## 검증

신규 테스트 `test_calib_verdict_distinguishes_undefined_from_low_correlation`:
`verify_ok`가 전부 True인 12건 → `corr is None` + verdict에 "판정 불가"·"한쪽" 포함.
표본 부족 경로도 함께 확인. 347 passed.

## 교훈

**"모름"과 "아니다"는 다른 값이다.** 통계 요약에서 정의 불가(None)를 극단값으로 축약하면 근거 없는
결론이 만들어진다. nullable을 0이나 최악값으로 뭉개지 말 것 — 이 프로젝트가 usage에서 이미 세운 원칙
("$0/0 tokens과 측정 불가(None)를 구분", v4.3.0 A-lite)을 캘리브레이션에는 적용하지 않고 있었다.
