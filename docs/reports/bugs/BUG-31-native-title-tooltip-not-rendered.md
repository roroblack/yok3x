# BUG-31 · 네이티브 title 툴팁이 프리뷰 렌더러에서 전혀 안 뜸

- **상태**: 수정 완료 (2026-07-22)
- **심각도**: 낮음(GUI 사용성 — 사용자 지적 "호버 어디? 안떠")
- **영역**: `gui/index.html` — 사용량 카드 호버 툴팁

## 증상

%통일 작업(토큰량을 본문 대신 호버로) 직후, `title` 속성 + CSS(`cursor:help`, 점선밑줄)까지 추가했는데도
사용자가 "아무것도 안 뜬다"고 재지적. 코드·서버는 정확히 서빙되고 있었음(curl·JS로 확인).

## 근본 원인

`title` 속성 툴팁은 **OS/브라우저 크롬이 그리는 오버레이**라 페이지 페인트 레이어 밖에 있다. 일부
렌더러(이 프리뷰 환경 포함)는 이 오버레이를 전혀 그리지 않는다 — 같은 렌더러 한계로 담당 에이전트의
스크린샷 캡처 도구도 이 세션 내내 반복 타임아웃했다(동일 근본원인의 다른 증상).

## 수정

`title=` 속성을 **`data-tip=`** 속성으로 교체하고, CSS `[data-tip]:hover::after{content:attr(data-tip)}`로
툴팁을 **페이지 콘텐츠 자체로 직접 그림**(OS 오버레이 의존 제거). 적용 지점: 상단 사용량 요약(`.plan.mono`)·
창별 리셋줄(`.rst`). 값은 `esc()`로 이스케이프(XSS 방지, 기존 패턴 유지).

## 검증

- curl로 서버가 새 `data-tip` 속성·CSS 정확히 서빙 확인.
- JS(`getComputedStyle`)로 `[data-tip]` 셀렉터 매치·`cursor:help` 적용 확인.
- 실제 `:hover` 트리거 스크린샷은 담당 에이전트의 도구 장애로 이번 세션엔 시각 확인 불가(코드 정확성은
  속성값·CSS 계산으로 확정 — `content:attr()`은 모든 최신 브라우저 표준 지원).

## 교훈

호버 정보를 **네이티브 `title` 하나에만 의존하지 말 것** — 일부 렌더링 컨텍스트(임베디드 프리뷰·특정
브라우저 설정)는 OS 레벨 툴팁을 그리지 않는다. 페이지 자체 CSS/DOM으로 그리는 방식이 렌더러 독립적이라
더 안전한 기본값이다. 관련: [[BUG-24]](GUI 표시 안전), 401c6b7(%통일 커밋).
