# BUG-22 · 전송이 작업별 보기에서 선택한 작업에 안 붙고 무제목/전체로 들어감

- **상태**: 수정 완료 (2026-07-18)
- **심각도**: 높음(핵심 기능 — 작업별 채팅이 안 됨, 사용자 보고)
- **영역**: `gui/index.html` — 작업별 보기(console-filter) ↔ 작업 이름(c-label) 연동

## 증상
작업별 보기에서 작업을 선택하고 하단에 목표를 입력해 **전송해도**, 그 작업이 아니라 **전체에
'무제목'으로** 런이 들어간다.

## 근본 원인
직전 변경("작업 이름을 CRUD 줄로 이동", `a2a564e`)에서 `c-label`을 저장작업 선택 시 **읽기전용으로만**
만들고 **값을 채우지 않았다**. 전송 경로 `buildSpec()`은 `spec.label = c-label.value`인데, 선택만 하고
값이 비어 있으니 `label=""` → 런이 라벨 없이(=무제목) 저장돼 전체 그룹에 들어갔다.
`console-filter`의 onchange가 `renderConsoleLog`만 부르고 **선택을 c-label에 반영하지 않은** 것이 핵심.

## 수정
`console-filter` onchange를 `onFilterChange()`로 교체 — **특정 작업 선택 시 그 라벨을 `c-label`에 반영**
(전송/저장이 선택한 작업 그룹으로 들어감). '전체'는 새 이름 입력을 위해 건드리지 않는다.

## 검증
- 작업 선택 → `c-label` 반영(읽기전용) → `buildSpec().label` = 선택 작업 → 전송이 그 작업으로 감.
- '전체'↔작업 왕복 후에도 정상. 런라벨(무제목 등) 선택도 반영. 182 passed(회귀 없음).
