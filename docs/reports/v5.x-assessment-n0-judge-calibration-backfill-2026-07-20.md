# v5.x · 평가 — N0: 과거 패치로 심판 교정(backfill) 실현성 · 2026-07-20

계획서 `v5.0.0-plan-nightly-self-improvement`의 **N0**(최우선) 실행 결과.
목표: "SCORE가 실제 성공·회귀를 구분하는가"를 **우리 git 이력**으로 지금 측정(F0 데이터 0 탈출).
**결론: backfill 불가 — 라벨 가능한 쌍이 실질 1~2개. 대안으로 변이(mutation) 기반 라벨링을 제안.**

## 무엇을 했나
1. **라벨링 방식 검증(성공)**: 버그 수정 커밋 `C`의 부모 `C^`에 worktree를 만들고 **현재 회귀 테스트**를
   적용 → 실패해야 "부모=broken" 라벨이 성립. **BUG-21로 실증**: 부모에서
   `test_rename_task_same_name_updates_label_in_place` **정확히 실패**, 수정본에서 통과.
   → **라벨 자체는 LLM 없이 기계적·무료로 만들 수 있음이 확인됨.**
2. **라벨 가능 쌍 전수 조사(실패)**: 최근 40커밋에서 "파이썬 회귀 테스트가 딸린 수정"을 추출.

## 왜 backfill이 안 되나 (핵심 발견)
| 커밋 | 성격 | 라벨 쌍? |
|---|---|---|
| `1358ec5` BUG-21 | 진짜 버그수정 + 회귀테스트 | ✅ 1개 |
| `5f78462` BUG-23 | 테스트 추가 + 수정(테스트가 그 커밋에서 처음 생김) | △ 경계 |
| `75e6c5e` ACQUIRE S2 | 기능 추가(버그 아님) | ❌ |
| BUG-19·20·22 | **GUI/JS** — pytest로 라벨 불가 | ❌ |
| BUG-17·18 | 라이브 환경 의존(토큰·CLI argv) — 재현 어려움 | ❌ |

**실질 라벨 쌍 ≈ 1~2개.** 우리 자신의 기준(`calibration.summarize`가 n<10을 "표본 부족"으로 판정)에
한참 못 미친다. 원인:
- 우리 버그의 상당수가 **GUI/JS**였다(파이썬 테스트 스위트가 라벨러라 커버 불가).
- 나머지는 **기능 추가**이거나 **라이브 환경 의존**(토큰 만료·CLI 심 등)이라 재현 라벨이 안 나온다.
- 수정과 회귀 테스트를 **같은 커밋**에 넣는 우리 습관상, 옛 시점에 "실패하는 테스트"가 존재하지 않는다
  (그래서 현재 테스트를 옛 코드에 **역적용**해야 하고, 그게 되는 경우가 드물다).

## 결과적 판단
- **자동 채택은 계속 금지**(계획서 N3). 심판이 "미교정"으로 판명된 게 아니라 **"교정할 데이터가 없다"** —
  어느 쪽이든 자율 승격의 전제가 없다.
- LLM으로 n=2를 채점하는 것은 **통계적으로 무의미**하므로 하지 않았다(비용 낭비 회피).

## 대안 제안 — 변이(mutation) 기반 심판 교정 [N0']
**아이디어**: 정상 코드에 **작은 결함을 주입**해 broken 변종을 대량 생성하고, **pytest 결과를 라벨**로 삼아
심판이 정상/결함을 구분하는지 측정한다. 라벨은 여전히 **기계적·무료**.
- 실현성 확인: `calibration.py` 한 파일에서만도 대표 변이 3종(비교 뒤집기·상수 변경·가드 무력화)이 **즉시 적용
  가능**. 대상 코드 6,163줄 · 라벨러 216 테스트 → **수십~수백 쌍** 생성 가능.
- 절차: 변이 주입 → `pytest`로 라벨(실패=broken) → **심판에게 블라인드 채점**(어느 쪽이 변이인지 숨김) →
  `calibration.point_biserial`·`confusion_at`로 판정.
- **한계(정직)**: 변이 결함은 **LLM이 실제로 내는 결함과 분포가 다르다**(distribution shift). 따라서
  "심판이 명백한 결함조차 못 잡는다"는 **하한 검사**로는 유효하지만, "실전에서 잘 판별한다"의 증명은 아니다.
  → 변이에서 실패하면 **결정적 부정 증거**(자동화 금지 확정). 통과해도 실전 검증은 별도 필요.
- 비용: 변이·라벨 생성은 $0. **심판 채점만 LLM 호출**(쌍당 1회) — 표본 20쌍이면 20회 수준으로 통제 가능.
