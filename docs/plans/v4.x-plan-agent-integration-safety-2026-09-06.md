# v4.x · 계획서 — 개인 에이전트(OpenClaw/Hermes류) 연동: `--unattended` 안전장치 + SKILL.md (V-12) · 2026-09-06

**구현 완료(2026-09-06)**.

## 배경

사용자 질문: OpenClaw·Hermes 같은 상시구동 개인 에이전트에서 yok3x를 편하게 쓸 수 있게
최적화하고 싶은데, 뭐가 필요하고 안전한가. 2026-09-06 기준 웹 리서치로 확인한 두 플랫폼의
공통 특성: **상시 구동 + 메시징/cron/webhook 같은 외부 이벤트로 트리거**된다(OpenClaw
38만+ GitHub 스타, 셸/파일/git 접근 시 코드 작성·커밋·배포까지 가능; Hermes는 이벤트 기반
에이전트 루프, "smart approvals 기본 켜짐"). 이건 yok3x가 지금까지 전제해온 "사람이 세션에서
직접 명령을 침"과 질적으로 다른 호출 방식이다.

## 기존 방어 장치로 부족한 이유 (코드로 확인)

사용자 질문("우리가 만들어둔 방어 규정으로 부족해?")에 대한 답 — **개별 장치는 이미
있지만 서로 묶여있지 않다:**

- `--auto`는 CLI 호출 단위 플래그라(`Orchestrator.__init__`이 `auto=None`이면 그때만
  `cfg.yok3x["auto_approve"]` 기본값을 씀) 전역 설정을 안 건드린다 — 이 자체는 안전하다.
- `guard.reservation.max_usd_per_run`(런당 비용 상한)이 이미 있다 — 하지만 **기본값 0(무제한)**
  이고, `orchestrator.py`의 강제 지점(`_run_task_file` 호출 전 체크)이 `_cap > 0`일 때만
  작동한다. **`--auto`와 이 상한을 묶어서 강제하는 코드는 어디에도 없었다**(직접 확인).
- MCP 전용 게이트(`_gate_mcp`)는 `auto_approve`를 우회하지 않지만, 이건 MCP 도구 호출에만
  적용되고 **핵심 런 자체의 게이트는 아니다.**

결론: "무인(사람이 그 순간 안 봄) + 무제한 지출"이라는 위험한 조합을 지금 코드가 막지
못한다. OpenClaw/Hermes가 메시지 하나로 `yok3x run task.json --auto`를 그대로 트리거하면,
상한 설정을 깜빡한 통합자는 이 조합에 그대로 빠진다.

## 구현

### 1. `--unattended` 플래그(신규, `--auto`와 별개)

기존 `--auto`(사용자 본인이 스크립트·루프에서 신뢰하고 쓰는 용도)는 그대로 두고, **외부
상시구동 에이전트 전용으로 새 플래그를 추가**했다(기존 동작 불변 — opt-in 원칙 유지):

- `yok3x run task.json --unattended`: `--auto`를 자동으로 내포(무인 호출은 사람이 y/n을
  칠 수 없으므로)하고, `guard.reservation.max_usd_per_run`이 설정 안 돼 있으면(0 이하)
  **워커를 한 번도 안 부르고** `cause="unattended_requires_cost_cap"`로 즉시 거부한다
  (fail-closed — R-6·MCP fail-closed와 같은 원칙).
- `Orchestrator.unattended` 필드를 추가해 `status.json`에 `unattended: true`로 기록(감사
  가능 — 이번 주 TeamFlow 토큰 사고에서 배운 "귀속을 나중에 재구성할 수 있어야 한다"는
  교훈 반영).
- `run_task_file()`/`_run_task_file()`에 `unattended: bool = False` 매개변수로 관통.

### 2. `SKILL.md`(Agent Skills 형식, `.claude/skills/yok3x-usage/SKILL.md`)

지난주 DisCo 논문에서 확인한 형식(SKILL.md가 Anthropic Agent Skills 사양과 동일 — Claude
Code뿐 아니라 이 사양을 지원하는 다른 에이전트도 그대로 읽을 수 있음)으로, yok3x 사용법과
**무인 호출 시 반드시 지킬 규칙**을 문서화했다. OpenClaw/Hermes가 이 형식을 지원하면
스스로 발견해 올바르게 쓸 수 있고, 지원 안 해도 사람이 그대로 참고 문서로 쓸 수 있다.
