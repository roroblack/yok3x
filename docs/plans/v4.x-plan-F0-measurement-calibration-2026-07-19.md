# v4.x · F0 — 측정 방법론 + 심판 캘리브레이션 계측 · 2026-07-19

로드맵 체크리스트 F0. codex 원칙: **"측정 기준·로그 요건·캘리브레이션 방법은 데이터 수집 전에 확정한다"**
(사후 기준 변경·필요 데이터 누락 방지). **실행(분석)만 데이터 축적 후.** 이 문서로 기준을 못박고,
`calibration.py`로 **로그부터 쌓기 시작**한다.

## 목적 (왜)
producer-reviewer 게이트의 정당성 검증: **LLM 리뷰어의 SCORE가 실제 `verify_cmd` 통과를 예측하는가?**
- SCORE≥pass_score와 verify 통과가 상관없으면 → **게이트는 연극**이고 producer-reviewer 루프는 낭비.
- CLIP 교훈("평가자를 지상진실로 검증")의 직접 적용. verify_cmd = 우리의 지상진실 라벨.

## 라벨 (지상진실)
- **`verify_ok`**: `verify_cmd`(테스트/린트) 실제 실행 결과. **verify_cmd 있는 런만 라벨 있음.**
- verify_cmd 없는 런(설계·기획 등)은 캘리브레이션 대상 아님(라벨 없음) — 기록은 하되 분석서 제외.

## 특징 (런당)
`final_score` · `verify_ok` · `rounds_used` · `total_tokens`(스텝 합) · `wall_ms` · `defect_count`(최종
리뷰 이슈 수) · `escalated`(bool) · `pattern` · `producer_backend` · `reviewer_backend` · `effort` ·
`materialized_files`(게시 파일 수 — "변경파일수" 대체, 워커가 직접 안 쓰므로).

## 지표 (분석 시)
- **상관**: `corr(final_score, verify_ok)` (point-biserial 근사, stdlib).
- **혼동행렬**: 게이트 예측(`final_score ≥ pass_score`) vs 실제(`verify_ok`) → TP/FP/TN/FN.
  - **정밀도**(게이트가 통과시킨 것 중 실제 통과) · **재현율**(실제 통과 중 게이트가 통과) · 정확도.
  - FP(게이트 통과했으나 verify 실패) = **위험한 오탐** — 별도 최우선 보고.
- **집단별**: backend·effort·pattern별로 위 지표 분해(어느 조합에서 SCORE가 못 미더운지).

## 주의 (codex)
- **선택 편향**: 우리는 **고른 경로의 결과만** 관측한다. SCORE↔verify는 같은 런에서 둘 다 관측되므로
  이 분석엔 편향이 적다. 단 **트리아지(T4)**의 "다른 티어였다면?"엔 shadow 데이터가 필요(F0 범위 밖).
- **비정상성**: 모델스택이 자주 바뀐다(sonnet→fable 등). 오래된 런의 상관은 금방 상함 → 분석 시
  **최근 N일 window** + backend/effort 태그로 분해해 본다.
- **표본 부족**: 런이 비싸 축적 느림. **분석은 라벨 런 ≥30 쌓인 뒤**(그 전엔 "표본 부족" 명시).

## 저장 (self-poisoning 금지)
- `.yok3x/calibration.jsonl` **append-only**(원자적 append). **knot에 저장 금지**(BUG-13 자기오염).
  런 산출물이 아니라 메타 계측이라 프롬프트에 절대 주입 안 됨.

## 구현 범위 (F0)
- `calibration.py`: `record_run(cfg, row)`(원자적 append) + `analyze(cfg, window_days=None,
  min_samples=30)`(라벨 런만 → 상관·혼동행렬·집단별, 표본<min이면 "부족" 반환). **순수 stdlib 통계.**
- 오케스트레이터: 런 종료 시 특징 추출해 `record_run`(모든 런 기록, verify_cmd 유무는 라벨로).
- `yok3x calibrate-report`(또는 함수): analyze 결과 출력. **데이터 없으면 "표본 부족" 정직 표시.**
- **하지 않음**: 선형모델·자동 게이트 조정(데이터 검증 후 별도). 지금은 **로그 + 분석 도구**만.
