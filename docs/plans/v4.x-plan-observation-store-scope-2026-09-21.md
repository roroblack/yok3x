# 결정 문서 · 런북·관측 로그의 저장 범위 (YOK-121)

- **작성**: 2026-09-21 · **상태**: 사용자 결정 대기 · **이슈**: YOK-121
- **계기**: RSIAgent 논문(arXiv 2609.15364)의 "탐색으로 쌓은 메모리를 다음 과제에 재사용" 구조와
  비교했을 때, 우리 쪽은 **쌓이는 곳이 작업폴더마다 갈라져 있다**는 점이 드러났다. 논문 내용은
  초록·요약 본문만 봤고, 이 문서는 우리 코드 사실에 근거한다.

## 문제

런북(V-1), 캘리브레이션(V-8), 리뷰 프로토콜 관측(T-6)은 전부 **그 런의 config 기준 `.yok3x/` 폴더**에
쌓인다. 근거 코드:

- 런북: [yok3x/runbooks.py:34](../../yok3x/runbooks.py:34) `cfg.paths.runs.parent / "runbooks.jsonl"`
- 캘리브레이션: [yok3x/orchestrator.py:1810](../../yok3x/orchestrator.py:1810) `cfg.paths.runs.parent / "calibration.jsonl"`

이 지표들의 공통 성질은 **표본이 `min_samples`(기본 5) 이상 모여야 쓸 수 있다**는 것이다
(`runbooks_min_samples`, `rounds_calibration_min_samples`). 그런데 작업폴더마다 따로 쌓이면
**한 폴더에서 5건을 채우기 전에는 힌트가 영원히 안 나온다.** 다른 폴더의 같은 유형 작업은 도움이 안 된다.

## 선택지

| 안 | 내용 | 이점 | 대가 |
|---|---|---|---|
| **A. 현 상태 유지** | 작업폴더별 저장, 손대지 않음 | 변경 0. 프라이버시·격리 그대로(폴더 A 의 기록이 폴더 B 에 안 새는 성질) | 표본이 안 모인다. 수동 합산이 계속 필요 |
| **B. 읽기 전용 집계 명령** | `yok3x observations --roots <경로들>` 이 여러 `.yok3x/` 를 읽어 합쳐 보여줌 | 저장 구조 무변경, 이미 있는 데이터를 바로 활용. 사람이 어느 폴더를 합칠지 통제 | 자동 힌트(런북·캘리브레이션 주입)는 여전히 폴더별. 명령을 사람이 돌려야 함 |
| **C. 사용자 전역 저장소** | `~/.yok3x/`(또는 설정 경로)에 복제 기록 | 자동 힌트가 여러 폴더 표본을 씀 | 폴더 간 정보 유입 — 격리 위배 가능. **어느 프로젝트의 작업 유형이 다른 프로젝트 힌트로 들어가는 것을 허용하는가**가 결정 사안. 마이그레이션·중복 정책 필요 |

## 권장

**B 를 먼저, C 는 B 로 필요를 확인한 뒤.**

- B 는 저장 구조를 안 바꾸고 관측성만 올린다. 이미 흩어진 18·5 건을 처음으로 한 화면에서 볼 수 있다.
- C 는 격리 성질을 바꾸는 결정이라 "표본이 정말 모자라서 힌트가 안 나오는 사례"를 B 로 확인한 뒤가 맞다.
  게다가 런북이 아직 0건이라 C 가 풀어줄 문제가 **현재 존재하는지부터 불확실**하다.
- 런북은 먼저 `use_runbooks` 를 실제로 켜서 기록이 쌓이는지부터 본다(이 결정과 별개의 선행 사항).

## B 안을 택하면 (구현 스케치)

- 입력: 루트 경로 여러 개(기본: 인자 없이 현재 config 하나). 각 루트에서 `.yok3x/*.jsonl` 을 **읽기만** 한다.
- 출력: 파일 종류별 건수, bucket×pattern 별 건수, `min_samples` 도달 여부. 원문·프롬프트는 이미 저장하지
  않는 설계라(런북은 고정 태그 어휘만) 합쳐도 새로 노출되는 것은 없다 — 다만 캘리브레이션·관측 레코드에
  경로 문자열이 들어 있는지는 **확인하지 않았다.** 구현 시 먼저 필드를 읽어 확인한다.
- 쓰기 없음, 백업 불필요. 시험: 빈 폴더·깨진 JSON 줄·없는 파일을 조용히 넘기되 건수에 반영.

## 사용자에게 필요한 결정

1. A / B / C 중 무엇으로 갈 것인가 (권장 B).
2. 런북(`use_runbooks`)을 켜 볼 것인가 — 켜면 프롬프트 뒤에 `APPROACH_TAGS` 요청이 붙어 토큰이 조금 늘고
   기록이 쌓이기 시작한다. 기본 off 를 바꾸는 결정이라 사용자가 정한다.

## 이 문서가 확인하지 않은 것

- 사용자 홈 등 `test_workspace` **밖**에 있는 다른 작업폴더의 기록.
- 각 jsonl 레코드의 필드 전체(집계에 필요한 키 이름은 구현 시 확인).
- 논문 전문.
