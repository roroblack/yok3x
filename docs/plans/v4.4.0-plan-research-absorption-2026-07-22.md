## 0. 검증 결과 — 정정 2건 (코드 대조 · codex 동의)

### 정정 1 — 리포트 7번(로컬 JSONL)의 "가장 큰 정확도 갭"은 **과대평가** → Tier2 강등
- 리포트 근거: "yok3x는 자기가 돌린 것만 알아 별도 터미널 사용 시 원장이 틀어진다."
- 확인(맞음): `usage.jsonl` 원장(`usage.py:3`)은 **yok3x 디스패치분만** 기록.
- 확인(틀림): 페이싱의 ground truth는 원장이 **아니라 공식 rate-limit reading**. `precise_weekly_pct`
  (토큰 추정치는 공식값과 5%p 이내일 때만 채택)·`effective_reset_at`(공식 reset_at 캐시)로 이미 앵커를
  공식값에 맞췄다. 별도 터미널 사용도 **공식 reading엔 잡힌다.**
- 결론: JSONL의 가치는 "정확한 현재 %"가 아니라 **세션·모델별 귀속과 사후감사**(codex). 게다가 Claude Code
  JSONL은 **비문서·불안정 포맷** → 폴백 가드 필수. **Tier2**로 강등.

### 정정 2 — 리포트 top-4(7→4→1→11)가 **활성 안전버그(F2-1)를 누락**
- 리포트 원문 #2(테스트 격리 = 기존 **F2-1**: mock 무력화 시 실백엔드 호출로 실쿼터 유출)를 최종 추천에서 제외.
- 그것은 "지금 발생 가능한 비가역 자원 유출"(codex). 정확도·자동화 개선이 앞설 수 없다. **F2-1 = 1순위 유지.**
