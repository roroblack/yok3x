사용자 제안: ①yok3x가 계획서·RULE·HISTORY를 숙지하고 **스스로 자기를 개발해 완성** ②매일 핫한 최신

독립 A/B → 사람 승격"으로 재설계.** 자동 채택은 아래 게이트가 서기 전엔 금지.

## 재설계 원칙 (codex 핵심 기여)
1. **문제 견인형(problem-pulled), 논문 밀어내기(paper-pushed) 아님.** 주제는 "핫한 것"이 아니라
   **우리 실측 병목**에서 나온다 — 안 그러면 "새롭고 구현하기 쉬운 아이디어"가 실제 병목을 밀어낸다(연구목표 탈취).
2. **연구와 구현을 격리.** 나이틀리는 **폐기 가능한 작업공간**에서 프로토타입만. 메인 자동 병합 없음.
3. **불변 보호영역(protected invariants).** 파일 보호로 부족 — **호출경로·기본값·가드 동작 자체를 불변식으로
   테스트**해 간접 약화를 잡는다.
4. **증거 기반 승격.** "점수 1점 높음"은 합격이 아니다(아래 합격선 참조).
5. **처리량 상한.** 매일 하나 생성이 아니라 **미검토 후보가 있으면 다음 생성을 정지**(리뷰 피로 방지).
6. **부정 결과 보존.** 실패한 접근을 기록해 같은 논문을 반복 구현하지 않는다.

## 합격선 — **전부 충족해야 승격**(codex, 결합 조건)
- `verify_cmd` 100% 통과 · **기존 회귀 0**
- **안전·승인·비용 불변식 통과**(보호영역 무결)
- 변경 전 고정한 **대표 작업군에서 baseline 대비 paired A/B**
- 성공률이 **의미 있게 증가** 하거나, 성공률 비열화 없이 **비용·지연 감소**
- **여러 실행에서 반복 재현**(seed·단일 문제 의존 아님)
- **복잡도 증가가 사전 예산 이하**(단조증가 방지)
- **숨겨진 holdout에서 방향 재현**
- **사람 검토 통과**

## 아키텍처
```
main (보호)            ← 사람이 승인한 것만
 └ nightly/<date>      ← 별도 브랜치
    └ <별도 폴더 복사본>  ← 폐기 가능 작업공간(격리 실행)
```
- **보호영역(자율 루프가 절대 수정 못 함)**: `guard`·`reserve`·승인 게이트·페이싱·`limits` 및 그 **기본값**.
  변경 시도 시 즉시 중단·보고. 불변식 테스트로 이중 방어.
- **자원 상한**: 나이틀리 1회당 비용·시간·반복 횟수 고정(C-2 예약 재사용). 초과 시 정지.
- **외부 권한 격리**: 논문 fetch는 **읽기 전용·샌드박스**, repo 스크립트 **실행 금지**(공급망 차단).
  가져온 텍스트는 **데이터로만** 취급(인젝션 방어 — 지시로 해석 금지).
- **비밀정보**: 로그·프롬프트·보고서에 자격증명·토큰 유출 금지(마스킹).

## 주제 선정 — 문제 견인형
"핫한 논문"이 아니라 **우리 병목**에서 역산. 현재 실측 병목:
1. **평가 신뢰성**(F0가 미교정 — 최우선) 2. **실패 국소화**(어디서 왜 실패했나) 3. **컨텍스트 효율**
4. **다중 에이전트 조정 비용** 5. **추론 비용·지연**.
→ 유효 주제: LLM 평가·캘리브레이션, 코드수정/SWE 에이전트, 실패 국소화, 프롬프트·컨텍스트 공학,
추론 효율. **뇌과학·신경과학은 보류** — 코딩 오케스트레이터에 직접 값하는 경로가 불명확하고
"그럴듯한데 무용"할 위험이 큼(원한다면 별도 탐색 트랙으로, 구현 대상 아님).

## 단계 (N)
- **N0 (최우선·1주) — F0 backfill로 심판 교정**: **우리 git 이력의 과거 패치**(BUG-19/21/22/23, ACQUIRE 회귀 등)를
  baseline/candidate 쌍으로 재생해 "SCORE가 실제 성공·회귀를 구분하는가"를 **지금 측정**한다(데이터 0 탈출).
  과거에 맞춘 뒤 **별도 holdout으로 확인**. → 심판이 미교정이면 **자동화 전면 보류**가 답.
- **N1 — 섀도 나이틀리 1회 완주**(자기개발 시스템 아님): 주제 1개 · 논문 ≤3 · **가설 1개** · 비보호 모듈 1개 ·
  신규 의존성 금지 · 비용/시간/반복 고정 · 폐기 가능 작업공간 · verify + 작은 paired A/B ·
  **자동 merge 없이 증거 보고서만** · 결과와 무관하게 실행 후 정지.
- **N2 — 루틴화**: N1이 안전하게 반복되면 스케줄. **미검토 후보 있으면 생성 정지**. 부정 결과 보존.
- **N3 — 자율 승격은 최후**: 위 합격선이 자동 판정 가능해지고 N2가 오래 안정된 뒤에만 논의. **지금은 금지.**

## 자기개발(제안 ①)에 대한 답
"스스로 완성"은 채택하지 않는다(C: 목표 미정의, A: 심판 미교정). 대신 **좁힌 형태**:
**사람이 정한 체크리스트의 다음 항목 1개를 실행 → 테스트 게이트 → 사람 검토에서 정지.**
(이 세션에서 사람이 운전해 이미 검증된 루프 = codex 구현·Claude 검토·체크리스트·테스트·커밋의 자동화.)

알려진 회귀 · 폐기 조건 · 롤백 방법`

## 추가 위험(codex, 대응 필수)
평가 오염(공개벤치·평가자 취향 과적합) · **심판 상관성**(구현자와 평가자가 같은 모델 → 같은 맹점) ·
선택 편향(성공만 기억) · **변경 귀속 실패**(한 번에 여러 변경 → 무엇이 효과인지 모름) · 플레이키 테스트 ·
공급망 실행 · 비밀 유출 · 리뷰 피로 · 브랜치 드리프트 · **운영 상태 증가**(diff는 작아도 캐시·예약·상태파일 누적).
→ **변경 귀속**을 위해 나이틀리는 **한 번에 가설 1개만**. **심판 상관성** 완화는 교차 패밀리(ARIS) 강제.

## 한 줄 결론
**"스스로 완성"이 아니라 문제 견인형 연구 → 격리된 1가설 섀도 구현 → 독립 A/B → 사람 승격.
외부 권한 격리·불변 보호영역·자원 상한·교정된 F0·회귀 0·복잡도 예산이 갖춰지기 전엔 자동 채택 금지.
첫 주는 시스템이 아니라 N0(과거 패치로 심판 교정) + N1(섀도 1회 완주)만.**
