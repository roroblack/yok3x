# HISTORY 아카이브 인덱스

활성 이력은 `docs/HISTORY.md`에 있다(이 폴더가 아님 — 참조가 깨지지 않게 활성본은 그대로 둔다).
`docs/HISTORY.md`가 **800줄 또는 80KB를 넘으면**(RULE §7.3) 오래된 **완전한 엔트리 묶음**을
순번형 `HISTORY-vNNN.md`로 이 폴더에 옮기고, 최신 30개는 활성본에 남긴다. 아래 표를 갱신한다.

| 파일 | 날짜 범위 | 버전 범위 | 엔트리 수 |
|---|---|---|---|
| [HISTORY-v001.md](HISTORY-v001.md) | 2026-07-04 ~ 2026-07-15 | v2.2.0 ~ v4.0.0 | 40 |
| [HISTORY-v002.md](HISTORY-v002.md) | 2026-07-16 ~ 2026-07-21 | v3.6.0(dev) · 계획 v4.1.0~v5.0.0 | 39 |

## 사용법
- "언제 무엇을 했지" 탐색: 이 표에서 기간/버전으로 파일을 고른 뒤 그 파일만 grep.
- 전체 검색: `grep -r "키워드" docs/HISTORY.md docs/history/`.
